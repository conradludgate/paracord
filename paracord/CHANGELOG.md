# Changelog

## 0.2.0 - 2026-11-05

### Breaking changes

- Seal the representation of keys generated by `custom_key!`. Safe code could
  previously construct a key with an index from another interner and then reach
  unchecked string resolution. The tuple field now uses an opaque, key-type-bound
  wrapper. Code that directly constructed or inspected the old `Key` field must
  use the generated constructors and string accessors instead.

### Fixed

- Restore compatibility of the arena helper with the declared Rust 1.73 MSRV.

The representation change retains four-byte keys and `Option` keys, existing
`Debug` output and the valid-key lookup path. It adds no allocation or lock.
